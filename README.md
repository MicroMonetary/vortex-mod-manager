# Vortex

### The official Nexus Mods manager

Vortex is the official mod manager from Nexus Mods, supporting 100+ games with a clean UI, automatic load ordering, and deep integration with the world's largest mod platform. The simplest way to manage your Nexus library.

<br>

---

## Features

| | |
|:---|:---|
| **Nexus Native** | Seamless one-click installation from the Nexus Mods website |
| **LOOT Integration** | Automatic load order sorting powered by the LOOT engine |
| **Collections** | Install curated community mod collections with a single click |
| **100+ Games** | Support for Skyrim, Fallout, Witcher, Cyberpunk, and dozens more |
